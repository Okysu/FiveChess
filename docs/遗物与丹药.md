# 遗物与丹药/符箓

> 数据：`src/data/relics/{common,uncommon,rare,boss,shop,event}.json`（84 件，`rl_*`）、`src/data/potions.json`（26 件，`po_*`）。
> 初始遗物（tier `starter`）由各主帅作者编写，不在本表。

## 已知 DSL 限制
- 召唤类丹药：召唤需要衍生物 ID，改用“发现一张随从并本回合 0 费”实现（召灵符）。
- “首张延时牌立即判定”无法缩短已挂载延时的倒计时，改为“首次打出延时牌时额外进行一次判定”（残页·星卷）。
- 星轨算筹的点数加成只作用于以己方为对象的判定（引擎按判定对象方计算），文本已写明。

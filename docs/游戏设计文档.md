# 《命阙》游戏设计文档（GDD）

> 版本 0.1 · 规则以本文与 `src/engine` 实现为准；二者冲突时视为 bug，以本文为修正目标。

## 1. 一句话定位

**《命阙》是一款东方幻想 Roguelike 构筑卡牌游戏：你把手牌献作“源”来支付命运，用余烬在敌方回合“应”对，在双排战线上布阵，并经营一副双方共享的天命牌堆——随机不是运气，而是可以改写的命数。**

老卡牌玩家上手十分钟后应能说出的差异：
1. “每张牌既是资源也是出牌——献不献是每回合的核心决策。”（区别于杀戮尖塔的固定能量、万智牌的地卡）
2. “敌人回合我也在打牌——留源防守还是全力进攻。”（区别于炉石的纯己方回合）
3. “判定可以被我窥视、重排、改判，命运流是一套构筑。”（区别于纯随机的暴击/闪避）
4. “前后两排 + 攻击距离，站位决定谁挨打。”（区别于炉石的单排）
5. “副将一来，这一局就换了打法。”

## 2. 世界观

**命书**：天地初开时，司命以星辰为墨写下众生的命数，每一行命数都是一张牌。凡人看不见命书，只能在“判定”时瞥见一角——翻开的那张牌，就是此刻的天意。

**命阙**：三百年前命书被撕裂，残页坠入大地深处，形成一座向下生长的倒塔——命阙。塔中每一层都是一段被扭曲的命数：死者不得安息，妖物被写成神明，王朝被写成废墟。传说走到命阙最深处的人，可以执笔改写自己的命。

**执命者**：能在判定时看见命牌、甚至伸手换掉它的人。玩家扮演的主帅都是执命者，各怀执念进入命阙；副将则是途中被主帅“改写”了命运而追随的人。

**天命牌堆**：战斗中翻开的天命牌是命书残页本身。四种命纹对应命书的四卷：
- **日纹**（阳）：显赫、征伐、焚烧之命
- **雷纹**（阳）：骤变、天罚、决断之命
- **月纹**（阴）：隐忍、流转、归藏之命
- **山纹**（阴）：沉稳、镇压、长久之命

**三幕与终幕**：
| 幕 | 名称 | 主题 | 首领候选 |
|---|---|---|---|
| 第一幕 | 残碑林 | 被遗忘者的墓园，碑文即命数 | 碑魇·无字、锈甲将军、噬名狐母 |
| 第二幕 | 沉渊城 | 被写成废墟的王城，沉在地下湖中 | 溺王·殷、千机傀儡师、双生判官 |
| 第三幕 | 星殿 | 司命的书斋，星辰坠落为灯 | 星蚀天狗、执笔童子、三足金乌之影 |
| 终幕 | 命书之心 | 命书的装订线，时间停止之处 | 司命（二/三阶段）；隐藏：无名之执 |

叙事载体：事件文本、首领战前后对白、主帅专属结局、图鉴条目碎片。

## 4. 核心规则

### 4.1 胜负
- 玩家主帅生命归零 → 冒险失败（战斗中生命即冒险生命，战斗间保留）。
- 敌方所有“要害”单位死亡 → 胜利。普通战斗中所有敌方单位都是要害；首领/精英战中首领是要害，首领死亡时其余敌方单位随之溃散。

### 4.2 战场
```
   [敌方主帅/首领位]
   [敌后阵 ×3]
   [敌前阵 ×4]
  ───────────────
   [我前阵 ×4]
   [我后阵 ×3]
   [我方主帅]  装备栏：武器 / 防具 / 坐骑 / 宝物
```
- **深度**：目标的深度 = 1 + 其所在阵营中位于其前方的“非空排”数量。前阵单位深度恒为 1；前阵为空时后阵单位深度为 1；主帅深度 = 1 + 非空排数量（+防御坐骑修正）。
- **攻击距离**：近战单位 1；【远射】无视距离；【奇袭】无视深度与【坚守】；主帅攻击距离 = 武器距离（无武器不能攻击）+ 进击坐骑修正。
- **近战单位只能在前阵发动攻击**；后阵近战单位不能攻击（后阵是保护与辅助位）。【远射】单位在任意排都能攻击。
- **坚守**：若攻击者距离内存在具有【坚守】的敌方单位，其普通攻击必须以其中之一为目标（【奇袭】、法术与效果不受限制）。
- **相邻**：同排左右相邻的格，以及前后排“对位”的格（后阵第 j 格与前阵第 j、j+1 格相邻：前 0-1↔后 0，前 1-2↔后 1，前 2-3↔后 2）。统御光环影响相邻格。
- **敌方无合法目标时的回退**：敌方攻击若没有距离内的合法目标，改为攻击深度最小的目标（不会因为站位而“免疫”攻击；站位的价值是决定“谁先挨打”）。

### 4.3 回合流程
**战斗开始**：洗混牌库；洗混天命牌堆（冒险级牌堆，每场战斗重新洗）；获得主帅初始源；“本命”牌放入起手；抽至 5 张；敌人生成第一轮意图；触发“战斗开始时”。

**我方回合**
1. 回合开始：所有源重置为可用；我方护甲清零（有【坚】类保留效果除外）；我方回合开始状态结算（灼烧）；我方身上的延时牌倒计时 -1，归零者依次判定；“回合开始时”触发。
2. 抽 5 张牌（牌库空时将弃牌堆洗入牌库）。手牌上限 10，超出的牌直接进入弃牌堆。
3. 行动阶段（任意顺序、任意次数）：打出手牌；献牌为源（每回合至多 1 次）；单位攻击（每单位每回合 1 次，入场当回合不能攻击，除非【疾行】）；主帅以武器攻击（每回合 1 次）；发动主帅主动技能。
4. 回合结束：我方回合结束状态结算（中毒、再生）；“回合结束时”触发（含手牌中的诅咒/状态牌）；状态层数衰减；然后计算余烬；弃置手牌（【藏锋】与【应】牌除外，【浮光】燃尽）。

**敌方回合**
1. 回合开始：敌方护甲清零；敌方回合开始状态结算；敌方延时判定；触发。
2. 按“首领位 → 前阵从左到右 → 后阵从左到右”的顺序，每个敌方单位执行其意图：**宣告 → 应对窗口 → 结算**。
3. 回合结束：敌方回合结束状态结算、衰减；余烬熄灭；弃置留手的【应】牌；为下回合生成新意图并公开。

### 4.4 献牌为源
- 每回合至多 1 次，把一张手牌面朝下献出，成为 1 枚**源**，本场战斗永久存在。
- 源的颜色 = 该牌流派色；中立牌、状态牌、诅咒牌献出为**素源**（只能支付通用费用）。
- 源上限 10 枚。达到上限后仍可献牌（触发【献】效果），但不再增加源。
- 被献出的牌本场战斗移出游戏（不进弃牌堆），战斗结束后回到牌组。
- 【献】关键词：该牌被献出时触发其献效果。
- 初始源：由主帅决定（通常 3 枚：2 主色 + 1 素）；招募副将后，初始源中的 1 枚素源变为副将颜色。

**费用**：`通用 N + 颜色要求`（例：`2+赤`）。颜色要求必须由对应颜色的源支付；通用部分可由任意源支付。X 费牌支付所有剩余可用源。

**自动支付**：引擎按“先付颜色要求，再用手牌最不需要的颜色付通用”的确定性算法选择源；表现层会高亮将被消耗的源。

### 4.5 余烬与应对
- **余烬**：我方回合结束时，仍可用的源中至多 `余烬上限`（基础 2）枚保持“可用”状态进入敌方回合，称为余烬；其余源熄灭。余烬只能用于支付【应】牌。
- **【应】**：可以在敌方单位宣告行动后、结算前打出（用余烬支付）；也可以在我方回合像普通牌一样打出（用源支付）。带“响应”字样效果（如“取消该行动”“改为以……为目标”）的应牌只能在应对窗口中打出。
- **应牌留手**：我方回合结束弃牌时，【应】牌不会被弃置，而是留在手中度过敌方回合；敌方回合结束时，仍未使用的【应】牌才被弃置（带【藏锋】者除外）。因此“留哪些应牌 + 留多少余烬”是每个回合末的决策。
- **冰冻/眩晕的应对**：在应对窗口中使宣告者陷入【眩晕】会使其本次行动失效；使其【冰冻】会使其本次攻击失效。
- **应对窗口**：仅当玩家手中存在“当前可支付且有合法目标”的应牌时才会打开；窗口带倒计时环（默认 8 秒，可在设置中调整或关闭）；可开启“自动跳过”。倒计时结束视为放弃。
- **连锁**：应对形成连锁，后进先结算（LIFO）。敌方宣告的行动是连锁底层；玩家的应牌在其之上；拥有手牌的首领可以再应对玩家的应牌；玩家可再应对。连锁深度上限 4。连锁中被“取消”的项不结算，但已支付的费用不返还。

### 4.6 天命判定
- **天命牌堆**：冒险级对象，初始为 4 命纹 × 点数 1–13 共 52 张。观星台、遗物、事件可以增删改天命牌。每场战斗开始时重新洗混。双方共享。
- **判定**：翻开牌堆顶一张作为判定牌 → **改判时机** → 依据命纹（日/雷为阳，月/山为阴）或点数确定结果 → 结算 → 判定牌进入天命弃堆 → 触发【天契】。牌堆空时将天命弃堆洗回。
- **延时**：延时牌挂在目标身上（每个目标至多 3 张），标有倒计时；在目标所属方回合开始时倒计时 -1，归零时判定并结算，然后离开。
- **窥视 X**：查看天命牌堆顶 X 张（结果对玩家公开保留，直到牌堆被洗混或顺序改变）。
- **观星 X**：查看顶 X 张，任意重排，并可将其中任意张置于底部。
- **命签**：将天命牌堆顶一张收入“命签”区（上限 2）。
- **改判**：判定牌翻开后，持有命签者可以打出一张命签替换判定牌（原判定牌进入天命弃堆）。改判时机顺序：判定目标的对手先、判定目标的拥有者后（即“对你不利的判定你总有最后一次机会”）。每次判定每方至多改判 1 次。
- 判定演出：居中翻牌；命纹揭示时播放专属光效与音效；改判时播放“替换”演出。

### 4.7 攻击与伤害
- 攻击：攻击者对目标造成等于其攻击力的伤害；若目标是单位且攻击者**不是**【远射】，目标同时对攻击者造成等于目标攻击力的反击伤害（主帅以武器攻击同样承受反击）。
- **伤害计算**（攻击与标注“攻击伤害”的效果）：`基础值 + 锋锐 → ×0.75（虚弱）→ ×1.5（易伤）→ 向下取整`；非攻击伤害（灼烧、中毒、效果伤害）不吃锋锐/虚弱，但吃易伤。
- **吸收顺序**：灵障（抵消整次伤害，移除 1 层）→ 护甲 → 生命。【中毒】伤害无视护甲与灵障。
- 【断魂】：对单位造成至少 1 点伤害（未被灵障/护甲完全吸收）即消灭该单位（对主帅/首领无效，改为额外 +3 伤害）。
- 【汲命】：造成伤害后，己方主帅恢复等量生命（攻击与反击都生效）。

### 4.8 结算顺序（定式）
1. **结算单元**：一张牌的效果、一次攻击、一个触发、一个意图动作都是一个结算单元，内部效果原子按书写顺序执行。
2. **触发排队**：结算单元执行过程中产生的触发不打断当前单元，而是进入**触发队列**（FIFO）。当前单元结束后先做**状态检查**，然后按队列顺序逐个结算触发；触发结算中产生的新触发追加到队尾（广度优先）。
3. **同时产生的触发排序**：行动方（当前回合方）的在前，非行动方在后；同一方内按**入场时间戳**升序（主帅视为时间戳 0，遗物 1，装备/阵地按装备/放置时间，单位按入场时间）。
4. **状态检查**：生命 ≤ 0 的单位同时死亡并离场，然后按“行动方在前、主帅→前阵左→右→后阵左→右”的顺序将【遗志】加入触发队列。主帅生命 ≤ 0 时立即判负/判胜（在遗志之前）；双方主帅同时归零时判玩家失败。
5. **攻击**：宣告 → 应对窗口 → 若攻击者与目标仍在场，双方同时造成伤害 → 状态检查。目标在应对中离场则攻击失效（敌方意图攻击则按回退规则重选目标）。
6. **判定被改判**：改判发生在“判定牌翻开”之后、“结果确定”之前；【天契】只对最终的判定牌触发一次。
7. **意图重算**：意图数值实时反映当前加成；意图目标在结算时若已不合法，按意图规则重选。

## 6. 状态
| 状态 | 类型 | 规则 | 叠层/衰减 |
|---|---|---|---|
| 灼烧 X | 减益 | 拥有者回合开始时受到 X 点伤害（可被护甲吸收） | 结算后层数减半（向下取整） |
| 中毒 X | 减益 | 拥有者回合结束时受到 X 点伤害（无视护甲与灵障） | 结算后 -1 |
| 冰冻 X | 减益 | 不能攻击（敌方攻击意图失效） | 拥有者回合结束 -1（在拥有者自己回合内施加的，跳过第一次衰减；易伤、虚弱同理） |
| 眩晕 | 减益 | 跳过下一个行动（敌方整个意图失效；我方单位/主帅本回合无法攻击与发动技能） | 生效后移除；移除后 1 回合内免疫眩晕 |
| 易伤 X | 减益 | 受到的伤害 ×1.5 | 拥有者回合结束 -1 |
| 虚弱 X | 减益 | 造成的攻击伤害 ×0.75 | 拥有者回合结束 -1 |
| 封印 | 减益 | 失去所有关键词与能力文本（不含已获得的数值） | 永久（本场） |
| 锋锐 X | 增益 | 攻击伤害 +X | 永久（本场），可为负 |
| 坚韧 X | 增益 | 获得护甲时 +X | 永久（本场） |
| 再生 X | 增益 | 回合结束时恢复 X 生命 | 结算后 -1 |

## 7. 卡牌
**类型**：随从（进入前/后阵成为单位）、策略（即时效果）、应对（带【应】的策略）、装备（进入主帅装备栏，同栏替换）、延时（挂载判定）、阵地（每方 1 个阵地位，新阵地替换旧阵地，可有持续回合数）。

**稀有度**：普通 / 稀有 / 史诗 / 传说。传说卡有专属登场演出与音效。

**升级**：每张卡可升级一次（+）。至少三分之一的升级改变机制（如增加关键词、改变目标范围、变为藏锋、费用颜色要求消失），其余提升数值。

**数值框架**（以 1 源 ≈ 杀戮尖塔 1 能量的 ~0.8 为基准，因源随回合增长）：
- 1 费：6 伤害 / 5 护甲 / 2-2 单位
- 2 费：10 伤害 / 9 护甲 / 3-3 单位
- 3 费：15 伤害或 AOE 7 / 4-5 单位
- 5 费：传说级改变战局；7+ 费：终结技
- 颜色要求每 1 个约抵 0.5 通用费的“强度溢价”

## 8. 主帅与副将
- 主帅 10 位（每色 2 位）：生命、初始源、初始牌组（10–12 张）、被动技能 + 主动/限定/觉醒技能之一、专属初始遗物。
- 副将 18 位：每位 1 个技能 + 1 种颜色权限。招贤节点（第二幕起）三选一；每局至多 1 位副将。
- 选择副将后：奖励卡池 = 主色 + 副色 + 中立；1 枚初始素源变为副色。

技能类型：
- **被动**：常驻。
- **主动**：每回合一次，可能需要费用。
- **限定技**：每场战斗一次。
- **觉醒技**：满足条件后永久（本场）转变，获得新能力。

## 9. 敌人
- 普通 45+、精英 12+、首领 9（每幕 3 选 1）、终局首领 2（司命 + 隐藏的无名之执）。
- 意图脚本：`循环`（固定序列）、`加权随机`（带“不连续重复”限制）、`条件分支`（如生命低于 50% 时狂暴，只触发一次）。
- 首领与部分精英拥有**手牌**：独立牌组、每回合“气”资源，出牌 AI 采用一步前瞻评估（克隆状态模拟候选出牌，按评估函数选最优）。
- 首领至少 2 阶段：生命首次降至阈值时，清除减益、播放阶段演出、更换意图脚本/牌组/立绘形态。

**意图图标语义**：攻击（剑，显示最终伤害 × 次数）、防御（盾）、增益（上箭头光）、减益（下箭头紫雾）、召唤（阵纹）、判定（命牌）、施法（手牌张数）、未知（问号）。数值为经过锋锐/虚弱/易伤实时计算的最终值。

## 10. 冒险结构
- 3 幕 + 终幕；每幕 15 层分叉地图（7 列 × 15 行网格，6 条随机路径合并）。
- 节点：普通战斗、精英、首领、事件、商店、营地（升级 / 删牌 / 恢复 30% 生命 三选一）、宝箱、招贤（第二幕起）、观星台（天命操控：删 1 张天命牌 / 复制 1 张 / 改 1 张命纹；或预览后续 3 个节点的具体内容）。
- 规则：第 1 层全为普通战斗；第 9 层全为宝箱；第 15 层之前一层全为营地；精英与营地第 6 层起才出现；同一路径上不连续出现精英/营地/商店。
- 终幕：营地 → 商店 → 司命。

**引导节奏（首局）**：第一幕前三战只出现献源、战线、意图；第一幕精英战教学应对窗口；第一幕首领战教学天命判定；第二幕开放副将。

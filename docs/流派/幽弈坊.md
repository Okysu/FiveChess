# 紫 · 幽弈坊

> 数据文件：`src/data/cards/P.json`、`src/data/commanders/P/commanders.json`、`src/data/relics/starter_P.json`、`src/data/lieutenants/P/lieutenants.json`

## 流派身份

幽弈坊是沉渊城下的一座棋坊兼赌坊，坊中人把天下当作棋盘：**弃子不是损失，藏着的子才最可怕**。机制上它是五色里**手牌操控最强**的一色：

- **抽弃循环**：大量 0～1 费过牌（影步、弃子、移花接木、絮影），“弃置”本身就是收益（`cardDiscarded` 触发、`discard` 的 `each`）。
- **连势**：`{combo:n}` 门槛与 `{count:"cardsPlayed"}` 线性增益，配合生成的[浮光]临时牌把一个回合拉长。
- **中毒**：无视护甲与灵障、按层衰减的慢性伤害，由“叠层 → 翻倍/扩散 → 兑现”三段组成。
- **藏锋**：留在手里等待爆发回合的牌；韬光养晦让整手牌都不弃置。
- **隐匿 / 奇袭**：单位不被点名，从侧翼直取后排与主帅。
- **降费**：`costMod` 在连势回合里挤出额外一两次出牌。

弱点：单张牌的即时数值偏低，护甲只有藏形、烟遁、千门赌客三个来源；中毒是慢伤，对“短命的高攻单位”和首领的清减益阶段效率不高；很多牌需要“先打几张垫牌”才能生效，手牌差时起不来。

## 规则要点（写给设计与玩家）

- **回合结束的弃牌也算“弃置”**：未被【藏锋】保留的手牌在回合结束时逐张弃置，会触发千门赌客、千面郎君、烂柯棋鬼、柳絮被动等。因此“弃牌流”不一定要主动弃，也可以故意留牌到回合末。【浮光】牌回合结束时是燃尽而不是弃置，不触发弃置效果。
- **韬光养晦与弃牌流互斥**：阵地期间回合末不弃牌，弃置触发只能靠主动弃牌。这是“藏锋爆发”和“弃牌收益”两条路线的取舍点。
- **连势计数**：`cardsPlayed` 是本回合此前已打出的张数（不含当前牌）；生成的 0 费临时牌（虚招、影针、絮影）都能计数。
- **中毒结算**：拥有者回合结束时受伤并 -1 层，无视护甲与灵障；`poisonDamage` 修正（昙香囊、蛊师）每次结算都生效。

## 构筑方向

### ① 暗毒（叠层 → 放大 → 兑现）

| 阶段 | 关键牌 |
|---|---|
| 施加 | 淬毒针（1 紫源 5 层）、瘴雾（群体，献出也施毒）、毒蛾（远射，造成伤害即施毒）、淬毒短匕（主帅攻击施毒，升级距离 2 不吃反击）、暗子 / 慢毒（延时判定阴纹施毒）、引蛇出洞（应：虚弱+中毒）、影针（衍生） |
| 放大 | 毒发（层数翻倍，升级只需 1 紫源）、蛊母（回合末给所有已中毒敌人追加）、蛊师（敌人中毒伤害 +1/+2）、昙香囊（夜昙初始遗物，+1） |
| 扩散 | **疫蛊蔓生**：先加毒，再把目标的层数复制给所有其他敌人；千面郎君（弃牌 → 随机/全体施毒） |
| 兑现 | 蚀骨（固定伤害 + 等同层数的伤害）、夜昙主动技“罗刹引”（每回合一次，伤害 = 层数） |
| 构筑核心（传说） | **万蛊噬心**：对每个敌人造成层数 ×2（升级 ×3）的无视护甲伤害。先毒发再噬心，是暗毒流的斩杀线。 |

取舍：蚀骨/罗刹引/万蛊噬心都**不消耗**层数，所以“先兑现、后翻倍”与“先翻倍、后兑现”的顺序决定一个回合的收益。

### ② 连势（短牌垫刀，一口气出完）

| 作用 | 关键牌 |
|---|---|
| 零费垫牌 | 影步（0 费抽牌，连势2 再抽；升级【藏锋】）、弃子、移花接木、昙刺（夜昙本命牌）、虚招/影针/絮影（衍生） |
| 生成临时牌 | 虚晃一枪（伤害 + 虚招）、分影（2 张影针，升级为影针+）、千机匣（每回合开始 1 张影针）、行云流水+（打出时给虚招） |
| 降费 | 移花接木（随机一张 ≥2 费手牌本回合 -1） |
| 回报 | 叠刃（每张 +2/+3 伤害）、千针（每张多打一发）、匿刃（连势3/升级连势2 伤害翻倍）、影舞者（每回合第 3 张牌后自动出手）、昙华一现、夜昙被动“昙影” |
| 收尾 | **收官**：【藏锋】等待，本回合每已打出一张牌伤害 +3/+4。 |
| 构筑核心（传说） | **行云流水**：本回合每打出一张牌抽 1 张。配合 0 费牌与衍生牌，一个回合可以把牌库翻一遍，最后用收官或千针收尾。 |

节奏：先铺千机匣或影舞者，下一回合用衍生牌把连势计数推到 4～6，再打叠刃/收官。

### ③ 弃牌与藏锋（弃子为势 / 藏锋待发）

| 作用 | 关键牌 |
|---|---|
| 主动弃牌 | 弃子（弃掉 ≥2 费的牌额外抽）、赌坊暗桩（起势换牌）、千丝面、絮影、弃车保帅（弃光手牌，每张抽 1）、烂柯棋鬼（起势弃光再抽回） |
| 弃置回报 | 千门赌客（每弃一张主帅 +2 护甲，回合末弃牌就是敌方回合的护甲）、千面郎君（每弃一张施毒）、烂柯棋鬼（每弃一张 2/3 点伤害）、柳絮被动（每回合第一次弃牌得絮影） |
| 藏锋 | 匿刃、袖里针（手牌越多越痛）、昙华一现、收官、影步+、烟遁+ |
| 整手保留 | **韬光养晦**：阵地 2/3 回合，回合末不弃手牌，手牌上限 +2；柳絮扇（手牌上限 +2） |
| 构筑核心（传说） | **烂柯棋鬼**：入场即弃光手牌再等量抽回，每弃一张 2 点伤害；之后每个回合末的弃牌都在打人。与弃车保帅连用，一回合就是十几次弃置触发。 |

两条子路线：
- **弃牌路线**：千门赌客 + 千面郎君 + 烂柯棋鬼，回合末故意留牌，用“弃置”本身换护甲、毒与伤害。
- **藏锋路线**：韬光养晦 + 袖里针 + 收官，攒 8～12 张手牌，下一回合一次打出。

## 与核心系统的咬合

- **献牌为源**：影狸（献：影针）、瘴雾（献：群体施毒）、慢毒（献：随机施毒）。衍生的[浮光]牌同样能献，献出的临时牌成为永久紫源——“生成牌”在幽弈坊也是资源。
- **应对窗口与余烬**：烟遁（任何时候都能打的护甲+抽牌，升级【藏锋】留作余烬应对）、引蛇出洞（削弱并毒宣告者）、镜花水月（改目标到你选的敌方单位，可让敌人自相残杀）、借刀杀人（按宣告者攻击力 ×2 反噬）、金蝉脱壳（取消行动，燃尽）。紫色应对牌全部控制在 1～2 源，余烬上限 2 也能打。
- **天命判定**：暗子（延时1）与慢毒（延时2）阳纹伤害/阴纹中毒，两个分支都有收益，配合金色的改判更稳；千术副将把改判变成过牌。
- **双排战线**：毒蛾、蛊师、蛊母、烂柯棋鬼偏后排且多为远射；影狸、影舞者带【隐匿】，影舞者/影狸+ 带【奇袭】绕过坚守直取后排与首领。

## 主帅

### 夜昙「影罗刹」— 暗毒 × 连势

- 生命 70，初始源 紫紫素；牌组 4 暗刃、4 藏形、2 昙刺、1 昙华一现。
- **昙影**（被动）：每回合打出第 3 张牌后，对随机敌人施加 3 层中毒。
- **罗刹引**（主动，1+紫）：对一名敌人造成等同其中毒层数的伤害。
- **昙香囊**：敌人受到的中毒伤害 +1。
- 打法：昙刺是 0 费的第 1、2 张牌，第 3 张牌触发昙影；昙华一现【藏锋】留到出牌多的回合。早期拿淬毒针、毒发、瘴雾把层数堆起来，每回合留 2 源开罗刹引；中期补影步、分影、千机匣让“第 3 张牌”稳定出现；终局毒发 → 罗刹引 → 万蛊噬心。

### 柳絮「千面客」— 弃牌 × 藏锋 × 生成牌

- 生命 74，初始源 紫紫素；牌组 4 暗刃、4 藏形、千丝面、袖里针。
- **絮影**（被动）：每回合第一次弃牌后，获得一张[浮光]絮影（0 费：抽 1 弃 1）。
- **换面**（主动，1）：弃 1 张牌，从 3 张随机幽弈坊牌中选 1 张加入手牌（本场留在牌库里）。
- **柳絮扇**：手牌上限 +2；战斗开始时抽 2 张（首回合 7 张起手）。
- 打法：换面每回合把一张烂牌换成一张紫卡，本身就触发被动；絮影再触发一次弃置。前期以千丝面挑牌、袖里针吃大手牌；中期根据拿到的牌选择“弃牌路线”（千门赌客/千面郎君/烂柯棋鬼）或“藏锋路线”（韬光养晦 + 收官/袖里针）。换面能在一局里多次接触传说牌，是最依赖临场判断的主帅。

## 数量与稀有度

- 基础 2：暗刃、藏形。本命/签名 4：昙刺、昙华一现、千丝面、袖里针。衍生 5：虚招、影针、絮影、蛊卵、蛊虫。
- 卡池 36：普通 16 / 稀有 11 / 史诗 6 / 传说 3；随从 9、策略 16、应对 5、装备 2、延时 2、阵地 2。
- 47 张紫牌全部可升级，其中 17 张为机制型升级（`qualitative`）。

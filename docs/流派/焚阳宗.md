# 赤 · 焚阳宗

> 数据文件：`src/data/cards/R.json`、`src/data/commanders/R/commanders.json`、`src/data/relics/starter_R.json`、`src/data/lieutenants/R/lieutenants.json`

## 流派身份

焚阳宗信奉“火不问来处”：进攻就是最好的防守，能烧掉的东西都可以变成力量。机制上它是五色里**最主动**的一色：

- **灼烧**是主要的持续伤害来源，由“叠层 → 放大 → 引爆”三段组成。
- **主帅兵刃**：赤色是唯一大量改写主帅武器的颜色（`weapon` 改攻击/耐久、给主帅【连斩】、“主帅攻击后”触发）。
- **献源爆发**：大量卡带【献】，献出时也有效果；并有按“本场献牌数”“源数量”结算的收尾牌，还有临时赤源（`energy`）做单回合爆发。

弱点：护甲与治疗很少，应对牌偏向“以攻代守”（反打、改目标），不擅长长期拖延；灼烧对高护甲敌人会被吸收一部分。

## 构筑方向

### ① 灼烧叠层（烧 → 放大 → 引爆）

| 阶段 | 关键牌 |
|---|---|
| 施加 | 引火（单体伤害+灼烧）、野火（群体灼烧）、赤尾狐（造成伤害即灼烧）、烬蛾（遗志/献都施加灼烧）、炎兆（延时判定灼烧）、燎幕（应对时灼烧宣告者） |
| 扩散/放大 | 燎原火鸦（回合结束为所有带灼烧的敌人追加；升级后对全体）、烈焰翻涌（翻倍；升级后全体翻倍）、焚心术士（敌人灼烧伤害+2） |
| 引爆 | 焚骨（灼烧层数×2 的伤害，随后清除/减半）、霍烬主动技“引焰入锋”（主帅攻击力+灼烧层数） |
| 构筑核心（传说） | **长明燎原**：敌人灼烧不再减半，并每回合给全体+1。配合烈焰翻涌、焚心术士，每回合的灼烧就是一次完整的伤害牌。 |

取舍：焚骨会清掉灼烧，与长明燎原是“收割 vs 养火”的对立选择；升级版焚骨只减半，可以兼顾。

### ② 兵刃连斩（主帅上阵）

| 作用 | 关键牌 |
|---|---|
| 获得武器 | 赤铜环刀（普通，升级后攻击附带灼烧）、焚阳长戟（距离2：可打后排、不受反击，攻击附带灼烧）、日炉匠（没有武器时自动装备赤铜环刀） |
| 强化武器 | 磨刃（攻击+耐久，无武器时给锋锐）、焚阳刀卫（起势强化武器）、日炉匠（每回合+攻击+耐久）、百炼炉场（主帅攻击力+2，每回合+耐久） |
| 额外出手 | 横刀（护甲+攻击）、刃舞（一次攻击连击2~3段，只耗1耐久）、迎刃（应：敌方回合用余烬让主帅出刀）、随锋剑侍（主帅攻击后跟一刀） |
| 构筑核心（传说） | **焚阳·断岳**：主帅获得【连斩】，每次攻击后武器攻击力+1。每回合两刀、刀刀变重；升级后距离2，不再吃反击。 |

注意：卡牌驱动的主帅攻击（横刀、刃舞、迎刃）会占用本回合的攻击次数，**先用普通攻击，再打这些牌**才能多出一刀。近战武器攻击单位会吃反击，搭配燎幕/横刀的护甲或百炼炉场+ 的“攻击后得甲”。

### ③ 焚源（献牌即燃料）

| 作用 | 关键牌 |
|---|---|
| 献出有收益 | 烬蛾、焚阳前锋、燃薪（献：临时赤源）、传薪（献：两张火种）、火种（衍生：献出抽牌）、朱羽祭 |
| 献牌燃料 | 祭火童子/传薪 产出火种；焚身献源（燃尽手牌直接换永久赤源） |
| 回报 | 朱雀雏（每献一张 +1/+1）、灰烬狂徒（按本场献牌数成长）、燎祭颂（按献牌数加伤）、炽源斩（按赤源数加伤）、万灯归一（按源数全体伤害，升级后【藏锋】等待满源） |
| 爆发 | 燃薪（净+1临时源，升级后不燃尽） |
| 构筑核心（传说） | **朱雀·焚羽**：在场时每回合可多献 1 次，每献一张对全体造成 3 点伤害；本场献满 5 张后死亡会回到手牌。 |

取舍：献得越多，牌库越薄、源越多——焚源流的节奏是前两回合疯狂献牌铺源，中后期用万灯归一、燎祭颂一口气打完。

## 与核心系统的咬合

- **献牌为源**：约三分之一的赤卡带【献】，每张都在“打出”与“献出”之间制造抉择。
- **应对窗口与余烬**：燎幕（守中带火）、迎刃（敌方回合出刀）、反焰（仅窗口：让攻击改打随机敌方角色，可能打自己）、烈阳反照（仅窗口：取消并按其攻击力×2 反噬）。
- **天命判定**：坠阳（阳纹追加全体灼烧）、炎兆、流火坠星（日纹 20 伤害）；与金色的窥视/观星/改判天然配合。
- **双排战线**：赤尾狐、燎原火鸦、焚心术士、朱雀·焚羽偏后排；焚阳长戟和断岳+ 让主帅够得着后排且不吃反击。

## 主帅打法

### 霍烬「断焰将军」（80 生命，赤赤素）
- 初始遗物**断焰刀鞘**：开战即装备断焰刀（3攻/距1/耐4）。耐久耗尽后刀会进入弃牌堆，重新抽到还能再装。
- 被动**焰随刀走**：主帅每次攻击后对目标施加2层灼烧。
- 主动**引焰入锋**（1源）：造成“主帅攻击力 + 目标灼烧层数”的攻击伤害，不占攻击次数也不耗耐久。
- 签名牌：焰脊斩（攻击+灼烧）、淬锋（补攻击/耐久，没刀就再装一把）。
- 节奏：每回合先普通攻击上灼烧，再用焰脊斩/横刀补刀，最后用引焰入锋把灼烧兑现。优先拿兵刃线（断岳、日炉匠、随锋剑侍、百炼炉场），再补灼烧放大（焚心术士、烈焰翻涌）。

### 离鸢「朱雀祭司」（70 生命，赤赤素）
- 初始遗物**朱雀翎**：开战时手牌多一张火种（献出抽牌），第一回合就能无损献牌。
- 被动**燎羽**：每献出一张牌，对随机敌人造成3点伤害。
- 觉醒**涅槃**：本场第4次献牌后恢复8生命，此后每回合可献牌2次。
- 签名牌：朱羽祭（献出时全体灼烧）、燎祭颂（按献牌数加伤，升级后全体）。
- 节奏：前3~4回合每回合都献，尽快觉醒；觉醒后每回合两次献牌（配合朱雀·焚羽则三次），被动与朱雀雏、朱雀·焚羽同时结算。收尾靠万灯归一、燎祭颂、炽源斩。注意她的护甲来源很少，前期靠献牌伤害清掉小怪。

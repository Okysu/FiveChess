# 《命阙》美术风格圣经

> **定稿方向：木版年画（Chinese woodblock New Year print）。**
> 经风格实验（`style-lab.html`，候选：16 位像素 / 粗颗粒像素 / 水墨写意 / 木版年画 / 皮影 / 墨线暗黑）由制作人选定。
> 否决理由备忘：皮影整体偏暖、五色难分；墨线暗黑与水墨的人物仍带西幻观感；像素未被选中。
> 风格参考样张：`art-src/style_refs/wb_*.png`（批量生成时作为 `/images/edits` 的参考输入）。

## 1. 总体原则
- **刻版感**：粗细一致的黑色刻线；形体靠线与平涂色块塑造，**不用渐变、不用喷枪、不做 3D 光影**。
- **矿物平涂色**：朱砂、石绿、石青、赭石（泥金）、墨、纸白；色块边缘干净。
- **套色错位**：色层与黑线之间允许 2–5px 的轻微错位——这是木版的“手作痕迹”，UI 中以“偏移印层”模拟。
- **纸纹**：所有大面积色块下可见宣纸纤维。
- **纹样装饰**：祥云、回纹、火焰纹、水波纹填充背景与留白，构图平面化、装饰化。
- **只用中国服饰与母题**：禁止西式板甲、哥特建筑、西式奇幻道具。

## 2. 色板
| 名 | 色值 | 用途 |
|---|---|---|
| 墨 | #1B1512 | 刻线、描边、印层阴影 |
| 纸 | #EADBB6 | 卡面底、文本框 |
| 朱砂 | #C8321F | 赤·焚阳宗、主按钮、应印 |
| 石绿 | #2F8A5F | 青·万木庭、次级按钮 |
| 石青 | #2A4F8A | 玄·镇岳门、费用盘、卡背 |
| 赭金 | #D9A23A | 金·观星阁、描边高光、选中 |
| 紫 | #6E3A78 | 紫·幽弈坊 |
| 素 | #A89A80 | 中立 |

每个流派仍使用全套矿物色，但由对应颜料主导（见 `scripts/art/style.ts` 的 `FACTION_TONE`）。

**命纹**（颜色 + 形状双编码）：日纹=赭橙实心圆+八芒；雷纹=紫折线；月纹=冰蓝新月；山纹=石绿三峰。阳纹实线外环，阴纹虚线外环。

## 3. 各幕色调
- 第一幕 残碑林：石绿、赭石、墨；断碑、古松、绿色鬼火纹。
- 第二幕 沉渊城：石青、朱砂、墨；水波纹、沉没朱柱。
- 第三幕 星殿：夜青、泥金；星云纹、坠星为灯。
- 终幕 命书之心：墨、金；流金飘带状光纹。

## 4. UI 规范（全部引擎内实现，零渐变）
- **面板 / 对话框**：生成的木刻回纹边框纹理（`ui/panel_light`、`ui/panel_dark`），以 9 宫格缩放。
- **按钮**：生成的祥云端头印版（朱砂 = 主要，石青 = 普通，石绿 = 次要，灰 = 禁用），9 宫格；悬停时印版抬起并露出墨色印层，按下时印版压回印层上（2–3px 位移）。按钮文字限制在印版面内，自动缩放。
- **卡牌**（300×420）：纸色卡身 → 插画窗（黑色刻线）→ 流派木刻边框（`ui/card_frame_<色>`，9 宫格）→ 流派名称缎带（`ui/ribbon_<色>`）→ 规则框（深纸色 + 偏移印层）→ 费用圆盘（`ui/cost_disc`）→ 攻/血徽（`ui/stat_atk` 刀形、`ui/stat_hp` 寿桃）。
- **选中/可打出高亮**：粗墨线 + 颜色线的双层描边（赭金 = 可打出，朱砂 = 应对，冰蓝 = 选中），不用柔光。
- **字体**：标题、按钮、数字统一使用粗宋体（Noto Serif SC 900，刻版字感）；毛笔体（Ma Shan Zheng）只用于游戏 Logo 与幕名。
- **标题字效**：赭金字 + 粗墨描边 + 朱砂偏移印层（无模糊阴影）。
- **图标**：圆形木刻章：墨底 + 粗黑外圈 + 细金内圈 + 平涂符号（第一枚定稿图标作为后续生成参考）。

## 5. 禁止事项
- 插画内不得出现任何文字、数字、字母、印章文字、水印、签名、边框。
- 不用渐变、喷枪、柔光、镜头光晕、玻璃质感、3D 渲染。
- 不用西式奇幻元素（板甲、哥特尖拱、西式龙等）。
- 不做血腥特写与裸露。

## 6. 生成流程（`scripts/art/`）
- prompt = 主体描述（数据中的 `art.subject`）+ 流派/幕色调 + 木版锁定后缀（`STYLE_LOCK` / `UI_STYLE` / `ICON_STYLE`）。
- 全部使用 `/images/edits` + 对应类别的木版参考图：卡牌 → `wb_card`，主帅/副将 → `wb_commander`，敌人/首领 → `wb_enemy`，背景/事件 → `wb_background`，UI → `wb_ui`，图标 → `ref_icon`。
- 立绘、敌人、图标、UI 部件用接口原生透明背景；失败时回退为 #FF00FF 品红底 + 色键抠图 + 边缘去溢色。
- 接口有速率限制（429）：并发 ≤4，客户端按服务端 “retry after N seconds” 自动重试。
- 质检：透明素材边缘截断检测、覆盖率检测，加人工审阅缩略图拼板。

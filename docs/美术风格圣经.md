# 《命阙》美术风格圣经

> 画风定稿：**东方幻想 × 厚涂插画（semi-realistic impasto painting）**。与炉石的西式卡通奇幻形成区分：更写实的人体比例、更厚重的笔触、更沉的色彩与更强的明暗戏剧性，辅以金箔、朱砂、墨色等东方材质点缀。

## 1. 总体原则
- **一眼可读**：小尺寸（手牌缩略、场上单位徽章）时主体轮廓清晰，明暗对比强，背景弱化。
- **材质叙事**：命书相关一律用“纸、墨、金箔、朱砂印”；五流派各有标志材质（见色板）。
- **光照统一**：主光为左上方暖光（约 10 点钟方向，45°俯角），右后方冷色轮廓光；阴影偏冷（蓝紫），高光偏暖（金橙）。
- **笔触**：可见的厚涂笔触与刮刀质感；边缘有虚实变化，主体边缘实、背景边缘虚；避免塑料感 3D 渲染与平涂动漫风。
- **角色比例**：7–7.5 头身，写实偏风格化；服饰取材中国古代（汉唐宋元明杂糅的幻想化），不做具体朝代考据。
- **构图**：卡牌插画为满幅，主体居中偏上，下三分之一留给规则框遮挡时不丢关键信息；角色看向画面内侧。

## 3. 各幕环境色调
- 第一幕 残碑林：雾白、苔绿、骨白、冷灰；断碑、古松、磷火。
- 第二幕 沉渊城：深水青、锈金、腐朽朱漆；沉没宫阙、水下光柱、溺者。
- 第三幕 星殿：午夜蓝、银白、星金；坠星为灯、悬浮书架、浑天仪。
- 终幕 命书之心：墨黑虚空、流金字迹（字迹只作光纹，不可读）、时间静止的尘埃。

## 4. 卡框规范（引擎内绘制，插画不含边框）
- 卡牌设计尺寸 300×420（比例 5:7），圆角 14。
- 分区（自上而下）：费用宝珠（左上，直径 64，数字 + 颜色要求小珠）→ 插画窗（268×196，距顶 22）→ 名称条（高 38，横跨，带流派色缎带）→ 类型行（小字：随从 · 稀有）→ 规则文本框（268×118，羊皮纸底，自动缩字）→ 随从攻/血徽章（左下剑形 / 右下莲瓣形）。
- 流派决定：外框金属色（赤=红铜、玄=玄铁、青=青玉、金=鎏金、紫=乌银、素=旧木）与名称缎带颜色。
- 稀有度：名称条中央的宝石（普通=无、稀有=蓝晶、史诗=紫晶、传说=金焰晶 + 外框流光）。
- 【应】牌：右上角固定朱红“应”字印章（UI 研究笔记结论：小尺寸也能识别）。
- 小尺寸（手牌缩略 < 120px 宽）必须保留：费用、名称前两字、类型图标、攻/血。

## 5. 图标语言
- 统一“鎏金描边 + 内部单色剪影 + 深色圆底”的徽记风格；线宽一致，45° 统一光源高光。
- 关键词图标：金色描边；状态图标：减益用该状态色的剪影 + 暗红底，增益用暖金底。
- 意图图标：剑（攻击）、盾（防御）、上扬火焰（增益）、下垂紫雾（减益）、阵纹（召唤）、命牌（判定）、展开手牌（施法）、问号（未知）。
- 地图节点：墨线 + 淡彩的“拓印”风格，与地图宣纸底一致。

## 6. 禁止事项
- 插画内**不得出现**任何文字、数字、字母、印章文字、水印、签名、边框、UI 元素。
- 不使用真实品牌、真实历史人物肖像、宗教符号的精确复刻。
- 不做血腥特写与裸露；恐怖元素以氛围表现为主。
- 不用霓虹赛博配色、不用平涂日漫风、不用低多边形 3D。
- 同一流派不得出现其他流派的主色大面积占比（点缀除外）。

## 7. 生成规范（`scripts/art/`）
- 每条 prompt = **主体描述**（数据中的 `art.subject`）+ **流派/幕 色调短语** + **统一风格锁定后缀**（见 `scripts/art/style.ts`）。
- 风格样张存 `assets/_style_refs/`，作为 `/images/edits` 的参考输入（用于图标、立绘等需要强一致性的类别）。
- 卡牌插画：1024×1024 不透明，满幅；运行时裁切为 4:3 插画窗，图鉴中展示完整方图。
- 立绘/单位/敌人/首领/图标/特效：使用接口原生透明背景（实测 `background: "transparent"` 可用）；若失败，退回 **#FF00FF 品红纯色背景 + 色键抠图 + 边缘去溢色**（主体含品红时改用 #00FFFF）。
- 质检：自动检测（透明素材边缘是否被截断、alpha 覆盖率是否合理）+ 人工审阅缩略图拼板（contact sheet），不合格重生成。

# 音频生成提示词（CC0 素材覆盖不到的部分）

这些声音目前仍由 WebAudio 实时合成。用任意音频生成工具生成后，把文件按下表的**文件名**放进 `art-src/audio/gen/`，然后运行：

```bash
npm run audio:import
npm run credits
```

生成的文件会自动接管对应音效/音乐（优先级高于 CC0 包），并记入素材清单与鸣谢页。

**通用要求**
- 格式：**mp3**（全浏览器都能播放；ogg 在旧版 Safari 上会退回合成音）或 wav；44.1 kHz。
- 音效：单声道或立体声均可；开头不要留白（≤20 ms），结尾自然衰减；响度约 −14 LUFS，别削波。
- 同一音效想要多个变体：`hit_1.mp3`、`hit_2.mp3`……会随机播放。
- 音乐与环境音：**必须能无缝循环**（首尾衔接），纯器乐，无人声、无歌词。
- 整体风格：中国传统乐器与民间音色（古琴、古筝、琵琶、二胡、笛子、箫、编钟、磬、木鱼、堂鼓、大锣），配合"木版年画 / 命运之书"的奇幻气质；避免日式（尺八/三味线主导）与西式管弦配器。

推荐工具：音乐用 Suno / Udio（选纯器乐 Instrumental）；音效与环境音用 ElevenLabs Sound Effects / Stable Audio。提示词用英文效果更稳定。

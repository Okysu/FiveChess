# 难度与平衡评估（2026-09）

> 对象：《命阙》全部 10 位主帅、3 幕 + 终幕、逆命 0–15。
> 工具：`scripts/balance-model.ts`（解析模型）、`scripts/simulate.ts` + `scripts/sim-batch.ts`（贪心 AI 全流程模拟）。
> 结论先行：**改动前，这个游戏对模拟 AI 来说几乎不可通关（0% 胜率、只有 11% 走出第 2 幕），而且解析模型显示即使“完美执行”的玩家在第 3 幕的生命预算也是负的。**第 2、3 幕和终幕的敌人数值相对于玩家成长曲线整体偏高约 30–45%。此外模拟 AI 有 4 个会让它“整场不出牌/卡死”的缺陷，使旧报告低估了主帅之间的差距以外还夸大了难度。修正后：逆命 0 下 AI 通关第 1 幕 84%、第 2 幕 52%、到达第 3 幕首领 27%、胜率 11%，逆命 0→5→10→15 单调变难，10 位主帅平均层数都在均值 ±20% 以内。

## 1. 方法

### 1.1 解析模型 `scripts/balance-model.ts`

```bash
npx tsx scripts/balance-model.ts [--asc=0] [--eff=1] [--md=.cache/sim/model.md] [--patch=what-if.mjs]
```

* **敌方**：对每个遭遇战的每个敌人，按其意图脚本（循环 / 加权 / 脚本→then）求出一个“移动周期”内的平均每回合伤害（攻击 = 攻击力×次数，判定按命纹 / 点数概率加权，延时牌按其判定分支，灼烧 / 中毒折算为总伤害，首领“施法”按能量 / 平均费用估算每次出牌数×牌的平均伤害），有阶段的敌人按血量比例混合各阶段；再乘以 `tuning.ts` 的幕×层级倍率与单独修正、逆命加成（A2–A4 生命、A8 伤害、A14 灵障）。敌人自身的护甲 / 治疗 / 召唤折算为有效生命。
* **玩家**：每张卡折算为“伤害当量 DE”（伤害 1、护甲 0.8、AoE ×1.8、每张抽牌 ≈ 4、状态按层数折算），随从按攻击×存活回合 + 生命×承伤。按真实规则做蒙特卡洛（150 次洗牌）：每回合抽 5、源 < 7 时献掉手里价值最低的一张（与模拟 AI 相同的献牌策略，因此源在第 4 回合封顶 7）、按 DE/费 贪心出牌；主帅技能与初始遗物按规则文本手工估价（见 `SKILL_PT`）。牌组阶段：起始、+3、+8 次奖励（奖励按真实稀有度分布三选一取最高 DE），第 2/3 幕外推到 +14/+20。
* **战斗**：逐回合结算：玩家先打（集火最低血，首领战最后打首领），敌方存活者造成伤害，扣除当回合护甲；得到击杀回合与失血。
* **生命预算**：按模拟器的选路偏好走 200 张随机地图，得到每幕期望的普通战 / 精英 / 营地数；预算 = 入幕生命 + 营地（半数用于休息 30%）+ 首领前必有营地。
* **执行效率 `--eff`**：玩家名义产出中真正落地的比例（溢出伤害、坚守 / 深度限制、没抽到对的牌、护甲打在敌人不攻击的回合）。**η≈0.65 可以复现贪心 AI 的普通战失血**（见 3.3），η≈0.85 近似熟练玩家，η=1 是理想上限。

模型是**粗粒度的筛查工具**：工具类效果（观星、改判、换牌）只粗略定价，模块化修正（光环、阵地的数值修正）不计价，因此卡牌“偏弱”名单里有若干误报（见 5.3）。真值以模拟器为准。

### 1.2 模拟器

```bash
npx tsx scripts/sim-batch.ts --runs=24 --asc=0,5,10,15 --tag=final   # 并行，≈8 分钟
npx tsx scripts/sim-batch.ts --runs=12 --asc=0,1,…,15 --commonSeeds    # 逆命阶梯，所有层级用同一批种子
npx tsx scripts/simulate.ts --runs=12                                  # 生成 docs/平衡报告.md
```

`sim-batch` 为每个（逆命, 主帅, 6 局一组）起一个子进程，合并逐局记录（每场战斗的遭遇战、入场 / 离场生命、回合、造成伤害、牌组大小），输出“通关第 1/2 幕、到达第 3 幕首领、通关第 3 幕、胜利”与按幕 / 层级 / 遭遇战的死亡率与失血。`--patch=x.mjs` 可在内存中改内容或倍率做 what-if 实验（本次所有主帅改动都先用它做过对照）。

### 1.3 AI 的修正（只修“使模拟失真”的明显缺陷，保持简单、确定）

| # | 问题 | 影响 | 修正（`src/engine/combat/autoplay.ts`） |
|---|---|---|---|
| 1 | 带「裂命之书」（每回合不能献牌）时，AI 仍然每回合先选“献牌”，引擎拒绝后它直接结束回合 | **拿到这件首领遗物后整场不出任何牌**，直接送命；是第 2 幕“满血进场、满血…然后死”的主因 | 献牌前检查 `canSacrifice`；额外献牌次数（双耳祭鼎、离鸢觉醒）也能用上 |
| 2 | 应对牌的目标选择：非“敌方”目标一律填我方主帅，遇到只能指向友方单位的应牌（移花接木等）时非法 | 应对窗口永远关不上，打满 60 回合上限判负 | 从 `cardTargets` 里选合法目标；模拟器对被拒绝的应答回退为“放弃” |
| 3 | 一步前瞻只看当前局面：武器、装备、阵地、挂在敌人身上的延时牌、锋锐 / 坚韧 / 再生 / 灵障、滋长都是 0 分 | 这些牌**从来不会被打出**（观星阁的延时流、焚阳宗的兵刃流整套失效），过牌小牌也不出 | 评估函数加入这些“持续价值”项；每打出一张牌 +0.5 |
| 4 | 从不使用丹药 | 人类一定会在精英 / 首领战用药 | 精英 / 首领战或生命 < 40% 时把丹药纳入候选；地图上生命 < 50% 时喝可在地图使用的药 |
| 5 | 普通战里只对“首领 / 精英”施加拖延惩罚 | 有治疗 / 护甲的普通战会被拖到回合上限 | 普通战所有敌人都算关键目标 |
| 6 | 观星只按阳 / 阴排序 | 按点数结算的判定（量天尺、九星断）吃亏 | 阳纹优先，其次高点数 |
| 7 | 冒险层：奖励每次必拿（直到 26 张） | 牌组膨胀 | 牌组 ≥ 18 张后不再拿普通卡（稀有 ≥2 仍拿到 28 张，史诗以上总拿） |

最终生成 `docs/平衡报告.md` 的 120 局（2320 场战斗）中 **0 次 AI 卡死、0 次被拒绝的 AI 操作**（`simulate.ts` 结尾会打印这两项）。

## 5. 剩余风险

1. **AI 的偏向**：一步贪心 AI 高估“挡满伤害”的防御型主帅（石韫、素弦）、低估需要规划的主帅（观星阁的观星 / 改判、幽弈坊的弃牌节奏）。主帅之间 ±20% 是对**这个 AI**成立的；人类的排序大概率不同。
2. **首领方差**：第 2 幕双生判官（36%）与第 3 幕三足金乌之影（47%）仍明显难于同幕其他首领；终幕司命对进入终幕的 AI 致死 40%、平均失血 67%。首领是每局固定抽取的，一局抽到最难的组合会显著更难。
3. **高逆命下主帅差距放大**（逆命 10：−42%…+51%）。逆命 6（生命 −10%）+ 8（伤害 +1）+ 11（初始源 −1）对 70 生命、零护甲的主帅叠加最重。
4. **样本量**：每个检查点 240 局，单个遭遇战只有 10–70 场，个别首领 / 精英的死亡率误差约 ±10 个百分点。
5. **并行改动**：评估期间协调者提交了石韫的新「岳镇」、冰冻 / 虚弱 / 易伤的计时修正，本文数字都已包含；此后任何规则改动都应重跑 `sim-batch`。
6. **规则改变型遗物**（4.4）没有被模拟覆盖。

## 6. 人类胜率会如何对照

* 贪心 AI 只把名义产出的约 **55–65%** 变成实际效果（它每步只看一步：不留余烬、不规划献牌、奖励只看稀有度、事件总选第一个选项、首领遗物总拿第一个）。熟练的构筑卡牌玩家按 η≈0.85 估算：每幕生命余量从 AI 的 +20～+50 升到 +65～+85，第 3 幕首领的期望失血约 25%（AI 约 47%）。
* 粗略换算（以 AI 胜率 11% 为锚）：
  * **首局 / 新手（刚学会献牌、应对窗口、判定）**：逆命 0 胜率约 10–20%，多数死在第 2 幕首领或第 3 幕。
  * **熟悉杀戮尖塔一类游戏的玩家**：逆命 0 约 40–60%；逆命 5 约 30–45%；逆命 10 约 15–25%；逆命 15 低于 10%。
  * **高手**：逆命 0 应当 >70%，逆命 15 的主要门槛是 A11（初始源 −1）+ A14（全体灵障）+ A15（司命第三阶段）。
* 主帅上手难度（对人类的预期）：石韫、阿苍、素弦最稳；夜昙、霍烬、离鸢靠速度；玄机子、燕无咎、柳絮上限最高但最吃理解。

### 建议试玩验证

1. 第 2 幕首领战（尤其双生判官）是否仍是最常见的死因；判官的“复活副手 + 按延时数加伤”对人类是否可读。
2. 三足金乌之影（灼烧型首领）：灼烧现在按倍率缩放层数，确认表现与意图预览一致、不会让人误判。
3. 石韫：新岳镇（判定式留存，阈值 1–6/7–10/11–13）的手感与强度；3 源的山君一怒是否仍值得每回合用。
4. 离鸢第 5 次献牌觉醒的节奏（大约第 4–5 回合），玄机子“改判得 4 甲”是否让他前期不再太脆。
5. 焚天炉心 / 金乌之影 / 玄武背甲 + 重峦 的终局构筑是否会让首领战失去威胁。
6. 逆命 7→8（普通敌人伤害 +1）仍是阶梯上最陡的一步（AI 第1幕通关 69%→45%）；A8 已改为倍率前加算，若人类也觉得断崖，可改为“+1，仅第2幕起”或“+10%”。
7. 终幕司命：第 3 幕通关后以 ≥90% 生命进入仍有约 40% AI 失败率——对人类应是“有压力但可赢”，需要确认不是“必须刷到特定构筑”。
